# 🏠 House Price Prediction using Linear Regression

This project predicts house prices based on features like lot area, quality rating, year built, basement area, living area, and garage size.  
It uses **Linear Regression** from scikit-learn to train and test the model.

---

## 📂 Dataset
The dataset contains **1000 rows** with the following features:
- LotArea
- OverallQual
- YearBuilt
- TotalBsmtSF
- GrLivArea
- GarageCars
- SalePrice (Target)

---

## ⚙️ Workflow
1. Data loading and preprocessing
2. Train-test split (80/20)
3. Feature scaling (MinMaxScaler)
4. Model training (Linear Regression)
5. Predictions
6. Model evaluation using MAE, MSE, RMSE, R²
7. Visualization (Actual vs Predicted Prices)
